# Микросервисный контур

`services/` фиксирует целевую декомпозицию StockFlow Market. На текущем этапе это инженерный каркас: контракты, события, миграции, исходники и тесты разложены по будущим сервисам, а реализация будет переноситься в них постепенно.

## Сервисы

| Сервис | Ответственность |
| --- | --- |
| `gateway` | Внешний HTTP/API слой, маршрутизация клиентских сценариев, агрегация ответов. |
| `catalog` | Товары, категории, атрибуты, публикация карточек. |
| `inventory` | Остатки, резервы, складские движения. |
| `orders` | Корзина, оформление, жизненный цикл заказа. |
| `pricing` | Цены, промо-правила, расчёт итоговой стоимости. |
| `search` | Индексация каталога и поисковые read-модели. |

## Локальные правила

- Каждый сервис владеет своими контрактами и схемой данных.
- Интеграции между сервисами сначала описываются в `contracts/` и `messaging/`.
- Общие зависимости не выносятся преждевременно: общий код появляется только после повторения реального сценария минимум в двух сервисах.
