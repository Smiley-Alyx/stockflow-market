# Сервис gateway

Внешняя точка входа для клиентских сценариев. Текущий Laravel-код в корне репозитория выполняет роль gateway и backend shell, пока доменные сервисы наполняются собственной реализацией.

## Зоны

- `contracts/` — внешние HTTP-контракты.
- `src/` — код gateway-слоя.
- `tests/` — контрактные и интеграционные проверки.
